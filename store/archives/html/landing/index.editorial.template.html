Avant de vous lancer

Bon à savoir.

De quelle version de macOS ai-je besoin ?

PK Monitor nécessite macOS 13 ou ultérieur. Le DMG prêt à l’emploi est disponible sur GitHub Releases ; les outils Xcode ne sont nécessaires que pour compiler l’application depuis ses sources. Consultez les notes de la release pour les architectures proposées.

Mes données restent-elles sur mon Mac ?

Le monitoring fonctionne localement. Si vous lancez volontairement un audit IA, les métriques, noms de processus, identifiants d’applications et chemins sont envoyés à l’endpoint que vous avez configuré. Votre clé API est enregistrée dans le Trousseau macOS.

La seconde barre demande-t-elle des permissions ?

Pour y déplacer les icônes d’autres applications, PK Monitor a besoin des autorisations Accessibilité et Enregistrement de l’écran. Elles servent à déplacer les icônes d’origine et à les redessiner dans la seconde barre. Les icônes sont restaurées lorsque vous désactivez cette fonction ou quittez PK Monitor.

Comment mettre à jour ou contribuer ?

Avec Homebrew, utilisez brew upgrade --cask pkmonitor. Sinon, récupérez le nouveau DMG et remplacez l’application. Pour signaler un problème, proposer une idée ou explorer le code, rendez-vous sur le dépôt GitHub de PK Monitor.
