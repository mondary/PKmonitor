Temps réel

Chaque pic a un nom.

La sparkline dessine l’activité de votre Mac en continu. VS Code compile, Chrome charge, WhatsApp appelle : l’icône de l’app dominante se pose sur le pic. Au survol, le panneau détaille tout.

Rangement

Une barre plus nette, façon Bartender.

Descendez les icônes secondaires dans une seconde barre : cases à cocher, ordre réglable, clic transféré vers le menu d’origine. Vous gardez l’accès, sans l’encombrement.

Confidentialité

Ce que votre Mac fait reste chez vous.

Tout tourne en local. Le conseiller IA est optionnel : analyse uniquement sur clic explicite, vers votre endpoint compatible OpenAI, clé API dans le Trousseau macOS.

Les vraies réponses.

Alors c’est gratuit, vraiment ?

Oui. PKMonitor est open source : le code est public, les releases sont libres, et il n’existe aucune version payante cachée.

Les données quittent-elles mon Mac ?

Non, sauf action explicite de votre part : l’analyse IA n’envoie des métriques qu’à l’endpoint que vous configurez, après un clic. La clé API reste dans le Trousseau.

Est-ce que ça ralentit le Mac ?

Non — app native SwiftUI, empreinte minimale, conçue pour rester dans la barre des menus sans se faire remarquer.

macOS requis ?

macOS 13 Ventura ou ultérieur, sur Intel comme sur Apple Silicon.

Allez, mettez-le dans la barre.

Une commande brew, quelques secondes, et votre Mac devient lisible.
