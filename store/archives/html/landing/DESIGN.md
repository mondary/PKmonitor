# PK Monitor — landing 2026

La page s’adresse aux utilisateurs Mac qui veulent comprendre leur machine sans
vivre dans le Moniteur d’activité. L’action principale est le téléchargement.

Direction : un objet éditorial clair et généreux, dans lequel les vrais panneaux
macOS bleus occupent une place centrale. L’orange exprime l’activité, le vert sauge
les informations système, le bleu les ressources et le lilas l’aide à l’analyse.
La signature est le passage entre une ligne d’activité, ses apps et le détail.

Palette : papier `#f5f4f0`, encre `#202220`, orange `#fb633d`, sauge `#e4e9df`,
bleu de données `#486eff`, graphite `#1c2223`. Orange sombre `#ac381d` pour les
petites légendes : le grand orange de titre ne sert pas aux textes fins.

Titres : Manrope Bold embarqué, licence OFL. Texte : police système. Données :
SF Mono / monospace. Aucun CDN, framework, système de build JavaScript ou backend.

Rythme : hero centré et vraie capture panoramique → Activity Line → jauges
interactives → arrêt et disque → seconde barre → film → audit → installation.
La démo utilise des données d’exemple explicitement signalées. Les captures et
le film proviennent de l’application, jamais d’une interface générée.

Motion : entrée typographique, trace animée et icônes, légère perspective de la
capture, apparition des sections, bascule continue de la seconde barre, transitions
de panneaux. Vidéo à la demande. Préférences de mouvement et pause globale.

Sources originales préservées : `store/index-v3.html`, captures CleanShot,
enregistrement du 14 septembre 2026, anciens projets vidéo.
