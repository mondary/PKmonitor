un moniteur dans la barre.

pkmonitor câble CPU, GPU, RAM, réseau et disque directement dans votre barre des menus — avec une sparkline qui nomme les apps derrière chaque pic. subagents non requis.

01 / sparkline

Les pics, nommés

Chaque pic porte l’icône de l’app dominante. VS Code compile, Chrome charge, WhatsApp appelle — vous le voyez.

02 / jauges

Cinq métriques

CPU, GPU, RAM, disque en deux lignes, réseau download/upload. Activables, réordonnables, colorables.

03 / seconde barre

Façon Bartender

Descendez les icônes tierces, réordonnez-les, gardez le clic vers le menu d’origine. Restauration au décochage.

le détail arrive au survol.

Pas de fenêtre à ouvrir, pas de dashboard à chercher. Le panneau liste les processus gourmands, leur part de CPU et de mémoire — et quitte l’app qui s’emballe en un clic. Le conseiller IA reste optionnel : clé au Trousseau, analyse uniquement sur clic explicite.
