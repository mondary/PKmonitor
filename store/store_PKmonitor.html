Fonctionnalités

Les signaux importants, pas le bruit.

01 · Sparkline

Chaque pic porte un nom.

La sparkline dessine l’activité de votre Mac en continu, assez compacte pour vivre dans la barre des menus. Quand un pic apparaît, l’icône de l’app dominante se pose dessus.

  • Icônes des apps sur les pics
  • Panneau au survol : processus, CPU, RAM
  • Arrêt propre d’une app en un clic
  • Alertes quand un processus s’emballe
02 · Jauges & réglages

Cinq métriques, cent façons de les poser.

CPU, GPU, RAM, disque en deux lignes et réseau download/upload : des jauges activables, réordonnables et colorables. Composez une barre des menus qui vous ressemble — ou disparaissez-la.

  • Réordonnancement par glisser-déposer
  • Couleurs par métrique
  • Densité réglable : compacte ou lisible
  • Thème clair / sombre automatique
03 · Seconde barre

Une barre plus nette, façon Bartender.

Descendez n’importe quelle icône tierce dans une seconde barre : cases à cocher, ordre réglable, clic transféré vers le menu d’origine. PKMonitor restaure tout au décochage ou à la fermeture.

  • Icônes tierces rangées, accès conservé
  • Clic transféré vers le menu d’origine
  • Permissions : Accessibilité + Enregistrement d’écran
  • Restauration automatique en sortie
04 · Conseiller IA

L’IA qui reste chez vous.

À la demande, le conseiller analyse les processus gourmands via votre endpoint compatible OpenAI : tableau récapitulatif, légitimité estimée selon nom/bundle/chemin, motifs des alertes et recommandations. Rien n’est envoyé avant votre clic explicite.

  • Endpoint OpenAI-compatible : le vôtre
  • Clé API dans le Trousseau macOS
  • Opt-in : 0 octet sinon
  • Analyse des processus dominants

FAQ

Les vraies réponses.

Quelles versions de macOS sont prises en charge ?

macOS 13 Ventura ou ultérieur, sur Mac Intel et Apple Silicon. L’app est universelle, native SwiftUI/AppKit, environ 27,4 Mo.

Les données quittent-elles mon Mac ?

Non, par défaut rien ne sort : aucun compte, aucun tracker, aucun envoi. Une analyse IA envoie uniquement à l’endpoint que vous configurez les métriques, noms, bundle identifiers et chemins des applications concernées — après un clic explicite. La clé API reste dans le Trousseau macOS.

Peut-on descendre des icônes tierces dans la seconde barre ?

Oui — Settings › Menu Bar Items : cochez les icônes à descendre, réordonnez-les, et PKMonitor les restaure au décochage ou à la fermeture. Permissions demandées uniquement pour cette fonctionnalité : Accessibilité (déplacer les icônes) et Enregistrement d’écran (les redessiner).

Est-ce que ça ralentit le Mac ?

Non. L’app est conçue pour rester discrète : échantillonnage léger, rendu compact, pas de Electron. Elle surveille précisément ce qu’elle affiche — rien de plus.

Combien ça coûte ?

Rien, pour toujours. PKMonitor est open source : code public sur GitHub, releases libres, soutien facultatif sur Ko-fi.
